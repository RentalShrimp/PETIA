# CONTRIBUTING - PETIA

## Objetivo

Este documento define como alterações no produto, código, documentação e decisões da PETIA devem ser propostas e incorporadas.

PETIA é um produto proprietário da HYPERION. Contribuição técnica não implica qualquer concessão de propriedade intelectual.

## Antes de alterar

Antes de iniciar uma alteração:

1. entenda o problema que está sendo resolvido;
2. verifique `VISION.md`;
3. verifique `PRINCIPLES.md`;
4. consulte `DECISIONS.md` para decisões existentes;
5. confirme se a alteração pertence ao escopo atual do produto;
6. evite introduzir complexidade antes de existir necessidade comprovada.
